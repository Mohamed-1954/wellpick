## What a page load sends

Pages are static files hosted on GitHub Pages. GitHub receives the requests needed to deliver a page, and its documentation says that when a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes, under the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). This site adds no analytics integration, session recording, newsletter signup, or embedded vendor form. If you download a worksheet, nothing you type into it on your computer is sent back to this site.

The Archivo Variable font is self-hosted, so no request goes to a font service. The light/dark theme toggle stores your choice in your own browser’s storage; clear site data to remove it.

## Video embeds

Product videos use a click-to-load facade. No request goes to YouTube, or to any third party, until you press play. Clicking loads the video from `youtube-nocookie.com`; from that point YouTube’s own policies apply to that embed.

## External links

Vendor links open the vendors’ own sites, which apply their own cookies, accounts, and retention practices. Do not put client details, credentials, or confidential records in URLs. The example workflows here are planning material, not live destinations.
